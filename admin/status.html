Requested tiles have first priority, followed by nearby prefetch, then zoom prefetch. Rendering counts jobs; each vector job can prepare up to four tiles. Waiting for timing samples.

Render queue time measures waiting for a worker, excluding the separate prefetch queue. A zero median means most renders started immediately. First tile ready measures worker start to its first saved PNG; Worker elapsed includes saving the full grid. Ready time ends before the PNG is sent. Response time includes sending it from this server, not Gaia displaying it. Resource waiting and CPU time can overlap; do not add the rows together.
